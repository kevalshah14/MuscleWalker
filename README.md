# MuscleWalker: Bio-Inspired Musculoskeletal Locomotion

## Project Overview
**MuscleWalker** is a bio-inspired robotics project that explores the control of bipedal locomotion using compliant muscle-tendon actuators. Unlike traditional robots driven by stiff torque motors, this project simulates a musculoskeletal system where forces are generated by contracting muscles that pull on tendons, mimicking the biomechanics of humans and animals.

The project utilizes **MuJoCo** for physics simulation and implements two primary control strategies:
1.  **Deep Reinforcement Learning (PPO):** Model-free learning for robust walking, jogging, and jumping gaits.
2.  **Model Predictive Path Integral (MPPI):** Model-based planning for dynamic balance and short-horizon control.

---

## Features
*   **Biologically Accurate Actuation:** Hill-type muscle models with series elastic tendons (Spring-Damper dynamics).
*   **Custom Gym Environments:** Gymnasium-compatible environments for Walk, Jog, and Jump tasks.
*   **Multi-Task Policies:** Separate trained agents for different locomotion styles.
*   **Visualizations:** Real-time rendering in MuJoCo with muscle activation feedback.

## Installation

### Prerequisites
*   Python 3.13+
*   [UV Package Manager](https://github.com/astral-sh/uv) (Recommended) or Pip

### Setup
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/kevalshah14/MuscleWalker.git
    cd MuscleWalker
    ```

2.  **Install dependencies:**
    ```bash
    uv sync
    # Or with pip:
    pip install gymnasium[mujoco] stable-baselines3 tensorboard
    ```

---

## Usage

### 1. Run Trained Policies (Testing)
Visualize the pre-trained agents performing different gaits.

*   **Walking:**
    ```bash
    uv run RL/test/walk.py
    ```
*   **Jogging:**
    ```bash
    uv run RL/test/jog.py
    ```
*   **Jumping:**
    ```bash
    uv run RL/test/jump.py
    ```

### 2. Train New Agents
Start training a new PPO policy from scratch.

*   **Train Walker:**
    ```bash
    uv run RL/train/walk.py --timesteps 1000000 --render
    ```
    *(Flags: `--render` to see training in real-time, `--log-episodes` to print progress)*

*   **Train Jogger/Jumper:**
    ```bash
    uv run RL/train/jog.py
    uv run RL/train/jump.py
    ```

### 3. Model Predictive Control (MPPI)
Test the model-based controller (no training required, computes control on the fly).
```bash
uv run MPPI/mppi.py
```

## Key Results
The project successfully demonstrates:
*   **Compliance:** The robot utilizes tendon elasticity to handle impacts naturally.
*   **Gait Emergence:** Distinct gaits (walking vs. jumping) emerge purely from reward function shaping.
*   **Robustness:** PPO policies can recover from minor disturbances due to the compliant nature of the actuators.
